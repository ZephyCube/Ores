# ZephyCubeOres v1.1.0

Extra ore veins for Overworld chunks near players (about double the vanilla amount, once per chunk) and double ore drops (not with Silk Touch). No Beta APIs.

## Install

Download `ZephyCubeOres-v1.1.0.mcaddon` from the Releases page and open it, or install by hand:

Copy the `ZephyCubeOres` folder into your world's `behavior_packs` folder, then add each pack's `uuid` and `version` (from its `manifest.json`) to the world's `world_behavior_packs.json`. Needs `@minecraft/server` 2.8.0.
